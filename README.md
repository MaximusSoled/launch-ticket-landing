# Launch Ticket Landing

Crie uma landing page (LP) de alta conversão para a venda de ingressos de um lançamento pago, utilizando os 3 PDFs anexados como referência:

PDF 1 e 2: referências visuais da LP para desktop e mobile.

PDF 3: copy completa da página.

Diretrizes:

Reproduza fielmente o design, o layout, a identidade visual e a experiência das referências, respeitando as particularidades de desktop e mobile.

Utilize a copy do PDF 3 integralmente, preservando textos, títulos, argumentos, CTAs e a ordem das seções.

Implemente uma página responsiva, visualmente refinada, com hierarquia visual clara, carregamento otimizado e foco em conversão.

Configure os CTAs para direcionar à compra do ingresso. Se o link de checkout não estiver disponível, deixe-o facilmente configurável.

Não invente textos, informações, depoimentos ou elementos ausentes dos materiais. Se algum detalhe estiver ilegível ou faltar, sinalize-o.

Objetivo: entregar uma LP funcional, fiel às referências visuais e à copy fornecida, pronta para revisão e publicação.
